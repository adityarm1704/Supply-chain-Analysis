## 📌 About the Project

The **Supply Chain Analysis Dashboard** is a data analytics project developed to understand business performance across different product categories and countries.

In this project, I used **MySQL** to analyze supply chain data, join multiple tables, and prepare relevant data for analysis. I then used **Tableau** to create an interactive dashboard that presents key business metrics and visual insights.

The dashboard provides an overview of total revenue, total orders, total profit, quarterly revenue trends, category-wise revenue, profit against benchmarks, delivery performance, and country-wise revenue.

The main objective of this project is to transform raw supply chain data into meaningful insights that help identify business trends, compare product and regional performance, and support data-driven decision-making.

---

## 🎯 Project Objectives

- Analyze overall revenue, order volume, and profit.
- Compare revenue across different product categories.
- Track quarterly revenue trends over time.
- Evaluate category-wise profitability against target benchmarks.
- Analyze delivery performance and order status.
- Compare revenue across different countries.
- Identify top-performing product categories and regions.
- Develop an interactive dashboard for business performance monitoring.
